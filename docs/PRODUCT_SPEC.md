# Product Spec — 找出那只猫

## 1. 产品目标

用最小开发成本验证一个适合中国区 IAA 变现的高重复休闲小游戏。

核心假设：
- 玩家 3 秒内理解玩法；
- 10–30 秒完成一关；
- 难度快速上升；
- 失败后产生“再试一次”的强烈动机；
- 提示、加时、继续是自然的激励广告场景。

## 2. 核心循环

首页 → 开始 → 显示目标特征 → 倒计时 → 玩家点击猫 → 正确则过关 / 错误则扣时 → 超时则重试或激励继续 → 下一关。

## 3. MVP 功能

### 必须有
- 首页
- 30 关
- 随机目标位置
- 倒计时
- 错误点击惩罚
- 关卡完成反馈
- 超时结算
- Mock 广告：提示 / +10 秒 / 继续
- 本地进度保存
- 手机竖屏适配

### 暂不做
- 猫养成
- 商城
- 抽卡
- 剧情
- PvP
- 公会
- 复杂账号系统
- 后端排行榜

## 4. 首版 KPI 观察项

浏览器内部测试阶段先埋接口，不设硬阈值：
- 开始游戏率
- 关卡完成率
- 各关失败率
- 平均单局时长
- 重试率
- 提示触发率
- 加时触发率
- 退出关卡

## 5. 平台路线

Phase 1：浏览器 MVP。
Phase 2：微信小游戏适配。
Phase 3：真实激励广告、分享、每日挑战与数据埋点。
