# Game Rules — 找出那只猫

## 基础规则

1. 每关出现 N 只猫，其中仅 1 只是目标猫。
2. 顶部文字提示目标差异，例如“找出没有胡子的猫”。
3. 玩家在倒计时结束前点击目标猫即可过关。
4. 点击错误猫会扣除时间，MVP 默认 -2 秒。
5. 时间耗尽后进入失败结算。

## 失败后的选择

- 重新挑战本关；
- 触发 `extra_time` 激励广告，获得额外时间继续；
- 部分模式后续可支持 `continue` 保留连胜。

## 提示

`hint` 激励广告完成后提供一种帮助：
- 缩小目标所在区域；或
- 让目标猫短暂闪烁。

MVP 优先实现“目标猫短暂闪烁”，逻辑最简单。

## 难度维度

难度不能只靠增加猫数量，应组合以下变量：
- 网格数量
- 目标差异大小
- 相似干扰项数量
- 时间限制
- 错误点击惩罚
- 目标描述复杂度

## 新手节奏

- Lv1–3：明显差异，快速建立成就感；
- Lv4–10：五官/颜色差异；
- Lv11–20：小差异 + 更多猫；
- Lv21–30：极小差异 + 相似干扰 + 更紧时间。

## 公平性原则

- 目标必须视觉上可辨认；
- 不做真正的“像素级不可见差异”；
- 难度来自搜索和注意力，不来自欺骗点击区域；
- 广告不是正常过关的强制条件。
